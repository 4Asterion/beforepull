# Security policy

## Supported versions

Only the latest published release receives security fixes. This repository is currently an initial, independently testable release candidate.

## Reporting vulnerabilities

Please use the **private GitHub vulnerability reporting** workflow if it is enabled for this repository. Otherwise contact the maintainer privately through a channel listed on their GitHub profile; do not post credentials or working exploits in public issues.

## Responsible use

Use sanitized test configurations and isolated fixtures. BeforePull does not deploy containers or access persistent data.

No promises of security or regulatory compliance are implied by a successful run.
