# Roadmap

This roadmap describes proposed work, not features already included.

- **v0.1:** deterministic Compose diff, severity-ranked findings, local HTML/JSON report, optional anonymous OCI manifest metadata discovery.
- **Next:** optional official release-note adapters with verifiable URLs and explicit provenance; image-index architecture comparison against a declared host platform.
- **Later:** policy-as-code rule packs, organization-specific check waivers with expiry, signed evidence manifests, GitHub Action wrapper, and opt-in canary test integrations.

Design rule: every claim needs a source and a confidence label; unknown is a first-class result.
